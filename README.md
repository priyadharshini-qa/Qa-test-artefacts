# 🧪 QA Test Artefacts

Welcome to the **QA Test Artefacts** repository!
This repository contains various QA process templates for testers

## 📂 Repository Structure

```
software-testing/
├── Defect_Template.xlsx
├── Requirement_Traceability_Matrix_template.xlsx
├── Test_Strategy_template.docx
├── Testcase-Template.xlsx
├── LICENSE
└── README.md
```
---

## 📄 Template Descriptions

| File | Description |
|------|-------------|
| `Defect_Template.xlsx` | Defect tracking sheet with severity, priority, and status fields |
| `Requirement_Traceability_Matrix_template.xlsx` | RTM to map requirements to test cases |
| `Test_Strategy_template.docx` | High-level test strategy document template |
| `Testcase-Template.xlsx` | Standard test case template with steps, expected results, and status |


## 🚀 How to Use

**Step 1:** Clone the repository
```bash
git clone https://github.com/priyadharshini-qa/Qa-test-artefacts.git
```

**Step 2:** Open the project folder
```bash
cd Qa-test-artefacts
```

**Step 3:** Open any template relevant to your testing phase and customise it for your project.
